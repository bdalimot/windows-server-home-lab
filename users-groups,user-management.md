# User Management

## Overview

This section documents the creation and management of user accounts
within the `HOMELAB` Active Directory domain.

The user account created for this lab is used to authenticate to
domain-joined Windows computers.

## Domain User

| Setting | Value |
|---|---|
| Username | bdalimot |
| Domain | HOMELAB |
| User Logon | HOMELAB\bdalimot |
| Domain | homelab.local |
| Domain Controller | DC01 |

The account was created using **Active Directory Users and Computers (ADUC)**
on the domain controller.
