## Windows Server Installation

DC01 was installed using Windows Server 2022 Standard Evaluation with
the Desktop Experience.

The virtual machine was created in VMware Workstation with the
following configuration:

| Setting | Value |
|---|---|
| Operating System | Windows Server 2022 |
| Edition | Standard Evaluation |
| Installation Type | Desktop Experience |
| CPU | 4 cores |
| RAM | 8 GB |
| Storage | 80 GB |
| Firmware | UEFI |
| Network Adapter | VMware NAT |

After installation, the server was renamed to:

`DC01`

The server was then prepared for use as the primary server in the
Windows Server home lab.
